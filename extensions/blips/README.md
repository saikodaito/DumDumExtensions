Short sounds while a reply comes in, inspired by Undertale and Animal Crossing.

- **Speech** ("in quotes") uses the character's voice; **actions** (*between asterisks*) use the same voice, lower and muffled; narration stays silent unless you turn it on.
- **10 synthesized voices**: Default, High, Deep, Robotic, Cute, Whisper, Retro, Bell, Static and Babble.
- **A voice per character**: pick a preset, tune pitch, speed and variation, or use **your own sounds** (up to 8 vowels and 8 consonants; each letter always plays the same sound, so a word always sounds the same).
- **The text keeps its pace**: the voice follows the reply and catches up when it falls behind.
- **TTS wins**: a reply the automatic TTS is going to read has no blips.

Not included in exported cards or backups.

Settings: Settings > Extensions > Voice Blips. Character voice: character editor > Blip voice.
